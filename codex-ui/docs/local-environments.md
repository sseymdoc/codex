# 本地环境与桌面项目兼容

**入口**：新建会话页的“选择环境”或输入框下方的环境胶囊 → 新建环境。填写名称、添加一个或多个源文件夹，再选择创建环境。当前在“本电脑”上时，表单预填当前文件夹及其名称。环境行悬停时末尾出现设置键（或按 →），打开“编辑环境”；“删除环境”在该对话框左下角。

**数据**：环境直接保存为 Codex app-server 的 `project/create` 记录，使用原生 `name`、`roots: [{ path }]` 和 `idempotencyKey`。读取、编辑及删除复用 `project/list`、`project/update`、`project/delete`。两个客户端使用同一 `CODEX_HOME` 时读取同一项目库；其他进程创建的项目可在重新连接后读取。这不涉及 ChatGPT 网页的云端项目。

**选择**：创建成功后选择新项目，首个源文件夹成为新会话工作目录；`thread/start.projectId` 指向该项目。多个源文件夹按原生格式保存，不额外扩大沙箱权限。环境菜单、新建页和输入框显示项目名称，重叠源文件夹的不同项目仍保留独立 ID。取消或失败保留原工作目录；失败表单保留输入，不创建本地假记录。不支持项目接口的旧服务会显示版本提示。

## 会话环境卡片

首行显示笔记本图标、会话所属环境名称和设置齿轮；工作目录显示名称及父路径，其他源文件夹逐行显示，长名称省略并可查看完整路径。目录按路径去重，保留复制路径和在终端中打开菜单。环境优先按会话的 `projectId` 读取，旧会话才按工作目录匹配；不会跟随新会话的环境选择。

齿轮复用新建环境表单，支持修改名称、添加和移除源文件夹，通过原生 `project/update` 保存并刷新卡片。保存不切换当前会话的工作目录，也不扩大沙箱权限。未归属项目的文件夹可从齿轮打开预填的新建环境表单。

本次验证：296 项自动测试通过，TypeScript 检查与生产构建通过；隔离 Chromium 中的环境设置和侧栏滚动回归共 20 组检查通过，包含长名称截断、重叠项目身份、保存失败与重试、空目录禁用、键盘焦点和 320 / 768 / 1024 / 1440 宽度。浏览器使用 RPC 夹具，未替换已安装客户端。
